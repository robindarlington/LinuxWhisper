Create src/linuxwhisper/config/loader.py with:
- `get_config_path() -> Path`: returns xdg_config_home() / "linuxwhisper" / "config.toml"
- `load_config() -> dict`: Loads config, creates default file if missing. Uses tomllib (stdlib 3.11+) for reading, tomli_w for writing defaults. Deep-merges user config over defaults so user only needs to specify overrides.
- `merge_config(defaults: dict, user: dict) -> dict`: Recursive deep merge where user values override defaults. Handles nested dicts properly.
- `write_default_config(path: Path)`: Writes DEFAULT_CONFIG to TOML file using tomli_w.dump(). Creates parent directories with mkdir(parents=True, exist_ok=True).

Update src/linuxwhisper/config/__init__.py to export load_config and get_config_path:
```python
from .loader import load_config, get_config_path
```

Implementation details:
- Use `import tomllib` directly (Python 3.11+ guaranteed by pyproject.toml)
- Use `from xdg_base_dirs import xdg_config_home` for XDG path
- Config file format is TOML per SYS-04 requirement
- Deep merge must handle arbitrary nesting (audio.sample_rate, logging.level)
