Create src/linuxwhisper/logging/setup.py:
- `setup_logging(config: dict)`: Configures Python logging. Reads level from config["logging"]["level"]. Logs to stdout (systemd captures this to journal). Format: "%(asctime)s - %(name)s - %(levelname)s - %(message)s". Sets root logger level.

Update src/linuxwhisper/logging/__init__.py to export setup_logging.

Create src/linuxwhisper/daemon/pid.py:
- `get_pid_path() -> Path`: Returns xdg_runtime_dir() / "linuxwhisper.pid". Falls back to Path.home() / ".local/run/linuxwhisper.pid" if xdg_runtime_dir() returns None or empty. Creates fallback directory if needed.
- `write_pid_file()`: Writes os.getpid() to PID file.
- `remove_pid_file()`: Removes PID file if it exists. Does not raise if already gone.
- `read_pid() -> int | None`: Reads PID from file, verifies process exists with os.kill(pid, 0). Returns None and removes stale PID file if process doesn't exist. Catches ValueError (corrupt PID file) and OSError (process gone).

Create src/linuxwhisper/daemon/lifecycle.py:
- `setup_daemon(config: dict)`: Called at daemon startup. Calls setup_logging(config), calls write_pid_file(). Stores config reference for reload.
- `shutdown_daemon()`: Called at daemon shutdown. Calls remove_pid_file(). Logs shutdown event.
- `reload_config()`: Called on SIGHUP. Re-reads config via load_config(). Updates logging level if changed. Logs reload event. Returns new config dict.

Create src/linuxwhisper/daemon/main.py:
- Module-level `running = True` flag.
- `signal_handler(signum, frame)`: On SIGTERM/SIGINT: sets running = False. On SIGHUP: calls reload_config().
- `run_daemon()`: Main entry point. Loads config via load_config(). Calls setup_daemon(config). Registers signal handlers for SIGTERM, SIGINT, SIGHUP. Enters main loop: `while running: time.sleep(0.1)`. On exit (running=False), calls shutdown_daemon(). Logs "LinuxWhisper daemon started" and "LinuxWhisper daemon stopped".

Update src/linuxwhisper/daemon/__init__.py to export run_daemon.

Create src/linuxwhisper/__main__.py:
```python
from linuxwhisper.daemon import run_daemon

```

`linuxwhisper start` command:
- Check if daemon is already running via read_pid(). If running, print "Daemon already running (PID {pid})" and exit.
- Fork daemon into background using subprocess.Popen with the daemon module: `subprocess.Popen([sys.executable, "-m", "linuxwhisper"], start_new_session=True, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)`.
- Wait briefly (0.5s) then verify daemon started by checking read_pid().
- Print "LinuxWhisper daemon started (PID {pid})" on success, or "Failed to start daemon" on failure.

Note: Phase 1 starts daemon directly via subprocess. Phase 7 adds systemd service for production use. This approach keeps Phase 1 self-contained without requiring systemd unit installation.

`linuxwhisper stop` command:
- Read PID via read_pid(). If not running, print "Daemon not running" and exit with error code.
- Send SIGTERM via os.kill(pid, signal.SIGTERM).
- Wait up to 3 seconds for process to exit (poll with os.kill(pid, 0) every 0.1s).
- Print "LinuxWhisper daemon stopped" on success, or "Failed to stop daemon (PID {pid})" if still running after timeout.

`linuxwhisper reload` command:
- Read PID via read_pid(). If not running, print "Daemon not running" and exit with error code.
- Send SIGHUP via os.kill(pid, signal.SIGHUP).
- Print "Configuration reload signal sent to daemon (PID {pid})".

`linuxwhisper status` command:
- Read PID via read_pid().
- If running: print "LinuxWhisper daemon is running (PID {pid})".
- If not running: print "LinuxWhisper daemon is not running".

Update src/linuxwhisper/cli/__init__.py to export cli.
