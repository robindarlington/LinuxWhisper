Create src/linuxwhisper/hotkey/permissions.py:
- `check_input_permissions() -> bool`: Check if current user is in the `input` group. Use `os.getgroups()` to get user's group IDs, then `grp.getgrnam('input').gr_gid` to get the input group GID. Return True if GID is in user's groups. Catch KeyError (group doesn't exist) and return False. Also check if running as root (os.geteuid() == 0) which always has access.
- `get_permission_instructions() -> str`: Return a multi-line string with instructions: "Add your user to the input group: sudo usermod -aG input $USER" and "Log out and back in for changes to take effect."

Create src/linuxwhisper/hotkey/detector.py:
- `class HotkeyDetector`:
  - `__init__(self, hotkey: str = "KEY_F13", device_path: str | None = None)`: Store hotkey as evdev keycode string. If device_path provided, use that device directly. Otherwise call `_find_keyboard()`.
  - `_find_keyboard(self) -> str`: List all evdev devices via `evdev.list_devices()`. For each, create InputDevice and check: (1) has `ecodes.EV_KEY` in capabilities, (2) name does not contain 'power', 'sleep', 'lid', 'video', 'consumer' (case-insensitive), (3) has a `phys` attribute (physical device). Prefer devices with `phys` containing 'usb' or 'input'. Return path of first matching device. Raise `RuntimeError("No keyboard device found. Check input group membership.")` if none found.
  - `_resolve_keycode(self, hotkey_name: str) -> int`: Convert hotkey string like "KEY_F13" to evdev keycode int. Use `getattr(ecodes, hotkey_name)`. If the config value doesn't have "KEY_" prefix, prepend it (e.g., "F13" becomes "KEY_F13"). Raise ValueError if keycode not found.
  - `start(self, on_press: callable, on_release: callable) -> None`: Open the InputDevice. Enter `device.read_loop()`. For each event with `type == ecodes.EV_KEY` and `code == self.keycode`: call `on_press()` if `value == 1` (key down), call `on_release()` if `value == 0` (key up). Ignore `value == 2` (key repeat). This method blocks -- it will be called from a dedicated thread by the pipeline coordinator.
  - `stop(self) -> None`: Close the device if open. Set a `self._running = False` flag checked in the read loop to break out.
  - `@property devices(self) -> list[dict]`: Return list of all detected keyboard devices (for diagnostics/logging). Each dict has keys: path, name, phys.

Use `evdev.InputDevice(path).grab()` to exclusively grab the device so the hotkey doesn't propagate to other applications. Call `device.ungrab()` in `stop()`.

Create src/linuxwhisper/audio/recorder.py:
- `class AudioRecorder`:
  - `__init__(self, sample_rate: int = 16000, channels: int = 1)`: Store sample_rate and channels. Initialize `self._queue = queue.Queue()`. Initialize `self._stream = None`. Initialize `self._recording = False`.
  - `_callback(self, indata, frames, time, status)`: Audio callback -- MUST NOT BLOCK. If status, log warning via `logging.getLogger(__name__).warning(f"Audio status: {status}")`. Put `indata.copy()` into `self._queue`. The `.copy()` is critical because sounddevice reuses the buffer.
  - `start(self) -> None`: Clear the queue (drain any leftover data). Create `sd.InputStream(samplerate=self.sample_rate, channels=self.channels, callback=self._callback)`. Call `stream.start()`. Set `self._recording = True`. Log "Audio recording started".
  - `stop(self) -> np.ndarray`: Call `stream.stop()` then `stream.close()`. Set `self._recording = False`. Drain queue into list of chunks. Concatenate with `np.concatenate(chunks, axis=0)` if chunks exist, else return empty array. Log "Audio recording stopped, captured {N} samples ({N/sample_rate:.2f}s)". Return the NumPy array.
  - `save_wav(self, audio_data: np.ndarray, output_path: str | None = None) -> str`: If output_path is None, create a temp file with `tempfile.mkstemp(suffix='.wav')`. Ensure mono: if `audio_data.ndim > 1`, take `audio_data.mean(axis=1)`. Convert float32/float64 to int16: clip to [-1.0, 1.0] then multiply by 32767 and cast to int16. Write with `scipy.io.wavfile.write(output_path, self.sample_rate, audio_int16)`. Return output_path. Log "Audio saved to {output_path}".
  - `@property is_recording(self) -> bool`: Return `self._recording`.
