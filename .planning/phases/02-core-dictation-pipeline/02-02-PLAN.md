Create src/linuxwhisper/transcription/engine.py:
- `class TranscriptionEngine`:
  - `__init__(self, model_size: str = "base.en", device: str = "cpu")`: Store model_size and device. Set `compute_type = "int8"` if device is "cpu", else `"int8_float16"` for GPU. Set `self._model = None` (lazy load). Log "TranscriptionEngine initialized with model={model_size}, device={device}, compute_type={compute_type}".
  - `load_model(self) -> None`: Load the model with `WhisperModel(self.model_size, device=self.device, compute_type=self.compute_type)`. Store in `self._model`. Log "Whisper model '{self.model_size}' loaded successfully". This is separated from __init__ so the daemon can control when the (slow) model load happens.
  - `transcribe(self, audio_path: str, language: str | None = None) -> str`: If `self._model` is None, call `self.load_model()` (auto-load on first use). Call `self._model.transcribe(audio_path, language=language, beam_size=5, vad_filter=True, vad_parameters={"threshold": 0.5, "min_speech_duration_ms": 250, "min_silence_duration_ms": 2000, "speech_pad_ms": 400})`. Join all segment texts with `"".join(seg.text for seg in segments).strip()`. Log "Transcription complete: {len(text)} chars, language={info.language} (prob={info.language_probability:.2f})". Return the text string.
  - `unload_model(self) -> None`: Set `self._model = None`. This allows garbage collection of the model to free memory. Log "Whisper model unloaded".
  - `@property is_loaded(self) -> bool`: Return `self._model is not None`.

Import from `faster_whisper import WhisperModel`.

  <action>
Create src/linuxwhisper/injection/detector.py:
- `detect_session_type() -> str`: Detect X11 vs Wayland session. Check in order: (1) `os.environ.get('XDG_SESSION_TYPE', '').lower()` -- if 'x11' or 'wayland', return it. (2) If `WAYLAND_DISPLAY` env var is set, return 'wayland'. (3) If `DISPLAY` env var is set, return 'x11'. (4) As last resort, try `subprocess.run(['loginctl', 'show-session', '-p', 'Type'], capture_output=True, text=True, timeout=2)` and parse output. Return 'unknown' if all methods fail. Log the detection result.

Create src/linuxwhisper/injection/wayland.py:
- `class WaylandInjector`:
  - `__init__(self)`: Check if ydotool is available: `shutil.which('ydotool')`. If not found, raise `RuntimeError("ydotool not found. Install with: sudo pacman -S ydotool")`. Check if ydotoold socket exists at `os.environ.get('YDOTOOL_SOCKET', '/tmp/.ydotool_socket')` or check `/run/user/{uid}/.ydotool_socket` as alternative path. If socket not found, raise `RuntimeError("ydotoold daemon not running. Start with: systemctl --user start ydotoold")`. Log "WaylandInjector initialized".
  - `type_text(self, text: str, delay_ms: int = 12) -> None`: Run `subprocess.run(['ydotool', 'type', '--key-delay', str(delay_ms), '--', text], check=True, timeout=10)`. Catch TimeoutExpired and CalledProcessError, wrap in RuntimeError with clear message. Log "Injected {len(text)} characters via ydotool".

Create src/linuxwhisper/injection/x11.py:
- `class X11Injector`:
  - `__init__(self)`: Check if xdotool is available: `shutil.which('xdotool')`. If not found, raise `RuntimeError("xdotool not found. Install with: sudo pacman -S xdotool")`. Check if DISPLAY env var is set. If not, raise `RuntimeError("DISPLAY not set - not an X11 session")`. Log "X11Injector initialized".
  - `type_text(self, text: str, delay_ms: int = 12) -> None`: Run `subprocess.run(['xdotool', 'type', '--delay', str(delay_ms), '--', text], check=True, timeout=10, env={**os.environ, 'LANG': 'en_US.UTF-8'})`. Catch TimeoutExpired and CalledProcessError, wrap in RuntimeError with clear message. Log "Injected {len(text)} characters via xdotool".

If 'unknown', try WaylandInjector first (catches RuntimeError), fall back to X11Injector, raise RuntimeError if both fail. Log which injector was created.
