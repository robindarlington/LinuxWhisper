Create src/linuxwhisper/pipeline/states.py:
- `class PipelineState(enum.Enum)`: Define states: IDLE, RECORDING, PROCESSING, INJECTING, ERROR.
- `VALID_TRANSITIONS: dict[PipelineState, set[PipelineState]]`: Map of valid transitions:
  - IDLE -> {RECORDING}
  - RECORDING -> {PROCESSING, IDLE} (IDLE for cancel/error)
  - PROCESSING -> {INJECTING, IDLE} (IDLE for empty transcription or error)
  - INJECTING -> {IDLE}
  - ERROR -> {IDLE}

Create src/linuxwhisper/pipeline/coordinator.py:
- `class DictationPipeline`:
  - `__init__(self, config: dict)`: Extract config values: hotkey from `config.get("hotkey", "F13")`, model from `config.get("model", "base.en")`, sample_rate from `config.get("audio", {}).get("sample_rate", 16000)`, channels from `config.get("audio", {}).get("channels", 1)`. Create component instances: `self._detector = HotkeyDetector(hotkey=hotkey)`, `self._recorder = AudioRecorder(sample_rate=sample_rate, channels=channels)`, `self._engine = TranscriptionEngine(model_size=model)`, `self._injector = create_injector()`. Set `self._state = PipelineState.IDLE`. Set `self._running = False`. Set `self._hotkey_thread = None`.
  - `_validate_transition(self, new_state: PipelineState) -> bool`: Check if transition from `self._state` to `new_state` is valid using VALID_TRANSITIONS map. Log warning if invalid. Return bool.
  - `_transition(self, new_state: PipelineState) -> None`: If `_validate_transition` passes, update `self._state` and log "Pipeline: {old_state.name} -> {new_state.name}".
  - `_on_hotkey_press(self) -> None`: If state is IDLE, transition to RECORDING. Call `self._recorder.start()`. Log "Recording started".
  - `_on_hotkey_release(self) -> None`: If state is RECORDING, transition to PROCESSING. Call `audio_data = self._recorder.stop()`. If audio_data is empty or too short (< 0.1 seconds = sample_rate * 0.1 samples), log "Recording too short, discarding", transition to IDLE, return. Save WAV: `wav_path = self._recorder.save_wav(audio_data)`. Transcribe: `text = self._engine.transcribe(wav_path)`. Clean up temp WAV file with `os.unlink(wav_path)`. If text is empty or whitespace, log "Empty transcription, skipping injection", transition to IDLE, return. Transition to INJECTING. Call `self._injector.type_text(text)`. Log "Dictation complete: '{text}'". Transition to IDLE. Wrap the entire processing sequence (after stop_recording) in a try/except that catches any Exception, logs the error, and transitions to IDLE (resilient -- never get stuck in a non-IDLE state).
  - `start(self) -> None`: Check permissions with `check_input_permissions()`. If no permissions, log error with `get_permission_instructions()` and raise RuntimeError. Pre-load Whisper model: `self._engine.load_model()` (do this at start so first dictation is fast). Log "Dictation pipeline started". Set `self._running = True`. Start hotkey detector in a daemon thread: `self._hotkey_thread = threading.Thread(target=self._run_hotkey_loop, daemon=True)`. Start the thread.
  - `_run_hotkey_loop(self) -> None`: Wrap `self._detector.start(on_press=self._on_hotkey_press, on_release=self._on_hotkey_release)` in try/except. On exception, log error. If `self._running`, log "Hotkey detector stopped unexpectedly".
  - `stop(self) -> None`: Set `self._running = False`. Stop the hotkey detector: `self._detector.stop()`. If recording, stop recorder. Unload model: `self._engine.unload_model()`. Log "Dictation pipeline stopped".
  - `@property state(self) -> PipelineState`: Return `self._state`.

Note on threading: The hotkey detector blocks in its read_loop, so it runs in a daemon thread. The _on_hotkey_press and _on_hotkey_release callbacks are called FROM that thread. The audio processing (_on_hotkey_release) runs synchronously in the hotkey thread -- this is intentional for Phase 2 simplicity. The hotkey detector won't receive new events while processing, which is acceptable because the user can't dictate while transcription is running anyway. If latency becomes an issue, Phase 5 can move processing to a separate thread.
