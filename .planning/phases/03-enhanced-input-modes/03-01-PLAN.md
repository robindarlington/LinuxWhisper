Implement `def resolve_hotkey_name(hotkey_str: str) -> str`:
  Takes a user-provided hotkey string and resolves it to a canonical KEY_ evdev name.
  1. Strip whitespace, convert to lowercase: `normalized = hotkey_str.strip().lower()`.
  2. Check FRIENDLY_ALIASES first: if `normalized in FRIENDLY_ALIASES`, return `FRIENDLY_ALIASES[normalized]`.
  3. Otherwise, apply the existing KEY_ prefix normalization: uppercase the string, if it doesn't start with "KEY_", prepend "KEY_".
  4. Return the resolved name.

Implement `def validate_hotkey(hotkey_str: str) -> tuple[bool, int | None, str]`:
  Validate a hotkey configuration string and return its evdev key code.
  1. Call `key_name = resolve_hotkey_name(hotkey_str)`.
  2. Use `getattr(ecodes, key_name, None)` to look up the code.
  3. If None, build a helpful error message. Collect available common keys: iterate FRIENDLY_ALIASES values (deduplicated) plus KEY_F1 through KEY_F24 that exist on ecodes. Sort them. Return `(False, None, f"Unknown hotkey: '{hotkey_str}'. Available keys include: {', '.join(available_display)}")` where `available_display` shows the user-friendly form (strip KEY_ prefix, lowercase).
  4. If found, return `(True, key_code, "")`.
