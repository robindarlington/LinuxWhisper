Add `def reload_config_safe() -> dict | None`:
  This is the state-aware replacement for SIGHUP handling. Steps:

  1. Access `_pipeline_ref`. If it is not None and `_pipeline_ref.state != PipelineState.IDLE`:
     - Log warning: `f"Config reload deferred: pipeline is {_pipeline_ref.state.name}. Will retry on next SIGHUP."`.
     - Return None.

  2. Log info: "Reloading configuration".

  3. Load new config: `new_config = load_config()`.

  4. Validate new config: `errors = validate_config_input(new_config)`. If errors is non-empty:
     - Log each error at ERROR level.
     - Log error: "Config reload aborted: validation errors in new config. Old config preserved."
     - Return None.

  5. Detect changes by comparing `_current_config` with `new_config`:
     ```python
     hotkey_changed = _current_config.get("hotkey") != new_config.get("hotkey")
     mode_changed = _current_config.get("mode") != new_config.get("mode")
     timeout_changed = _current_config.get("toggle_timeout") != new_config.get("toggle_timeout")
     ```

  6. If hotkey changed: check compositor conflicts for new hotkey via `check_compositor_conflicts(new_config.get("hotkey", "HOME"))`. Log any conflicts as warnings. Log info: `f"Hotkey changed: {_current_config.get('hotkey')} -> {new_config.get('hotkey')}"`.

  7. If mode changed: log info: `f"Mode changed: {_current_config.get('mode')} -> {new_config.get('mode')}"`.

  8. If timeout_changed: log info: `f"Toggle timeout changed: {_current_config.get('toggle_timeout')} -> {new_config.get('toggle_timeout')}"`.

  9. Update logging level if changed (same logic as existing `reload_config`):
     ```python
     old_level = _current_config.get("logging", {}).get("level", "INFO") if _current_config else "INFO"
     new_level = new_config.get("logging", {}).get("level", "INFO")
     if old_level != new_level:
         setup_logging(new_config)
         logger.info(f"Logging level changed: {old_level} -> {new_level}")
     ```

  10. Update stored config: `_current_config = new_config` (use global declaration).

  11. If `_pipeline_ref is not None` and any of (hotkey_changed, mode_changed, timeout_changed):
      - Call `_pipeline_ref.update_config(new_config)`.
      - If hotkey_changed:
        - Log info: "Restarting hotkey detector for new key..."
        - Call `_pipeline_ref.restart_hotkey_detector()`.

  12. Log info: "Configuration reloaded successfully".
  13. Return `new_config`.

Keep the existing `reload_config()` function unchanged but add a docstring note: `# Note: prefer reload_config_safe() for state-aware reload (Phase 3+)`.

The existing `get_current_config()` function is already present and correct -- no changes needed.

   # Check for compositor binding conflicts (informational only)

       logger.warning(
           f"Hotkey '{config.get('hotkey', 'HOME')}' may conflict with compositor bindings. "

       )
