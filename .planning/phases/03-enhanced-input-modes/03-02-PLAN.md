Update src/linuxwhisper/daemon/lifecycle.py:
- Add imports: `from linuxwhisper.config.validation import validate_hotkey, validate_config_input, check_compositor_conflicts` and `from linuxwhisper.pipeline.states import PipelineState`.
- Add a module-level variable `_pipeline_ref = None` to hold a reference to the DictationPipeline instance.

- Add `def set_pipeline_ref(pipeline) -> None`: Store `pipeline` in module-level `_pipeline_ref`. This is called by daemon/main.py after pipeline creation so lifecycle can access it during reload.

- Add `def reload_config_safe() -> dict | None`:
  This replaces the current `reload_config()` for SIGHUP handling. Steps:
  1. Check if pipeline is in a safe state to reload. Access `_pipeline_ref`. If `_pipeline_ref` is not None and `_pipeline_ref.state != PipelineState.IDLE`:
     - Log warning: `f"Config reload deferred: pipeline state is {_pipeline_ref.state.name}. Will apply on next idle."`.
     - Return None (reload deferred).
  2. Log "Reloading configuration".
  3. Load new config from disk: `new_config = load_config()`.
  4. Validate the new config: call `validate_config_input(new_config)`. If there are errors, log each error at ERROR level, log "Config reload aborted due to validation errors", and return None.
  5. Detect what changed by comparing `_current_config` with `new_config`:
     - `hotkey_changed = _current_config.get("hotkey") != new_config.get("hotkey")`
     - `mode_changed = _current_config.get("mode") != new_config.get("mode")`
  6. If hotkey changed: check compositor conflicts for new hotkey via `check_compositor_conflicts(new_config.get("hotkey", "F13"))`. Log any conflicts as warnings.
  7. Update logging level if changed (same as current `reload_config`).
  8. Update stored `_current_config = new_config`.
  9. If pipeline ref exists and (hotkey_changed or mode_changed): call `_pipeline_ref.update_config(new_config)`. If hotkey_changed, log "Hotkey changed. Restarting hotkey detector..." and call `_pipeline_ref.restart_hotkey_detector()` (this method will be added to the pipeline in the action for this task -- see below).
  10. Log "Configuration reloaded successfully".
  11. Return new_config.

- Keep the existing `reload_config()` function but mark it with a comment `# Legacy: use reload_config_safe() for state-aware reload`. Do not remove it to avoid breaking anything during transition.

- Add `def get_current_config() -> dict | None`: Return `_current_config`. This was already referenced in Phase 2 Plan 03 but may not exist yet -- add it if missing.

Also update src/linuxwhisper/pipeline/coordinator.py (this file is in Plan 01's ownership but this task needs to add one small method):
- Add `def restart_hotkey_detector(self) -> None` to DictationPipeline:
  1. If `self._state != PipelineState.IDLE`, log warning and return (should not happen since reload_config_safe checks, but defensive).
  2. Stop the current hotkey detector: `self._detector.stop()`.
  3. Wait for hotkey thread to join (with timeout=2).
  4. Re-read hotkey from config: `hotkey = self._config.get("hotkey", "F13")` (where self._config is updated by update_config).
  5. Create new detector: `self._detector = HotkeyDetector(hotkey=hotkey)`.
  6. Start new hotkey thread: same pattern as start().
  7. Log "Hotkey detector restarted with key={hotkey}".

Note: The pipeline coordinator's `update_config` method (from Plan 01) should also store the full config: `self._config = new_config`. Ensure Plan 01 stores the config dict in `self._config` during `__init__`.
