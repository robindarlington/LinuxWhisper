<objective>
Build the complete overlay module as a self-contained package that can render a live audio waveform in a small non-focus-stealing window.

Purpose: The overlay provides visual feedback during recording — the user sees a waveform that moves with their voice, confirming the mic is active. This is the entire overlay subprocess, from the OverlayManager API (spawns/kills the subprocess) to the GTK4 window with layer-shell positioning and Cairo waveform rendering.

Output: A working `src/linuxwhisper/overlay/` package. Running `python -m linuxwhisper.overlay` shows the overlay window. `OverlayManager` can spawn/kill it and pipe amplitude data to it.
</objective>

  <action>
Create the overlay package with three files:

**`__init__.py` — OverlayManager class (public API used by the daemon):**
- `OverlayManager` class with methods: `show()`, `hide()`, `send_amplitude(rms: float)`, `is_running() -> bool`
- `show()` spawns `subprocess.Popen([sys.executable, "-m", "linuxwhisper.overlay"], stdin=subprocess.PIPE, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)`. Store process reference.
- `hide()` calls `process.terminate()` then `process.wait(timeout=2)`, sets process to None. Wrap in try/except for already-dead process.
- `send_amplitude(rms)` writes `f"{rms:.4f}\n".encode()` to process.stdin, calls flush(). Wrap in try/except (BrokenPipeError, OSError) — silently ignore pipe errors (overlay may have died).
- `is_running()` checks process is not None and `process.poll() is None`.
- Accept optional `config: dict` in constructor for future configurability (position, size). Store it. Default to empty dict.

**`__main__.py` — Subprocess entry point:**
- CRITICAL: Load `libgtk4-layer-shell.so` via `ctypes.CDLL` BEFORE any `gi` imports. Wrap in try/except OSError to set `_layer_shell_available = False` if not installed.
- `gi.require_version('Gtk', '4.0')` then import Gtk, GLib.
- If layer shell available: `gi.require_version('Gtk4LayerShell', '1.0')` and import Gtk4LayerShell as LayerShell.
- Parse optional config from argv (overlay width, height, position) using simple argv parsing — or just use hardcoded defaults (200x60, bottom-right) for now since config comes from the daemon side. Keep it simple.
- Create `Gtk.Application(application_id='com.linuxwhisper.overlay')`, connect 'activate' to handler that calls `create_overlay_window()` from `window.py`.
- Call `app.run(None)` (no argv forwarding to GTK).
- The `on_activate` handler should: create the window (from window.py), create the WaveformWidget (from waveform.py), add it to window, create StdinReader targeting the widget and start it, then present the window.

**`reader.py` — StdinReader class:**
- `StdinReader(waveform_widget)` — stores reference to WaveformWidget.
- `start()` — spawns a `threading.Thread(target=self._read_loop, daemon=True)` and starts it.
- `_read_loop()` — iterates `for line in sys.stdin:`, strips, parses float, calls `GLib.idle_add(self._widget.push_amplitude, rms)` to safely push to GUI thread. Catches `ValueError` for malformed lines — skip silently. When stdin closes (EOF/pipe broken), call `GLib.idle_add(self._request_quit)`.
- `_request_quit()` — calls `self._app.quit()` if app reference is set. This handles the case where the daemon terminates the stdin pipe (overlay should exit).
- Store an `_app` reference set via `set_app(app)` method so it can quit on EOF.
- `stop()` — sets `self._running = False`.

**`window.py` — GTK4 window creation with layer-shell and X11 fallback:**
- `create_overlay_window(app: Gtk.Application) -> Gtk.Window` function.
- Create `Gtk.Window(application=app)`, set `set_default_size(200, 60)`, `set_decorated(False)`, `set_resizable(False)`.
- Check if layer-shell is available AND supported: import the `_layer_shell_available` flag from `__main__` module OR accept it as a parameter. Better: pass `use_layer_shell: bool` parameter.
- **If layer-shell available:**
  - `LayerShell.init_for_window(window)` — MUST call before present()
  - `LayerShell.set_layer(window, LayerShell.Layer.TOP)` — above normal windows
  - Anchor to bottom-right: `set_anchor(BOTTOM, True)`, `set_anchor(RIGHT, True)`
  - Margins: `set_margin(BOTTOM, 20)`, `set_margin(RIGHT, 20)` — 20px from edges
  - `set_keyboard_mode(window, LayerShell.KeyboardMode.NONE)` — CRITICAL: no focus stealing
  - `set_namespace(window, "linuxwhisper-overlay")` — compositor identification
  - `set_exclusive_zone(window, -1)` — don't push other windows
- **If layer-shell NOT available (X11 fallback):**
  - The window is already undecorated. Just present it. GTK4 removed set_keep_above and set_accept_focus, so on X11 we rely on the window being small and undecorated. The window will appear in the default position. This is acceptable as X11 is a degraded experience per research.
- Apply CSS for polished appearance: `border-radius: 8px; background-color: #2164AD;` via `Gtk.CssProvider`. Use `load_from_string()` and `Gtk.StyleContext.add_provider_for_display()`.
- Return the window.

**`waveform.py` — WaveformWidget (Cairo DrawingArea):**
- `WaveformWidget(Gtk.DrawingArea)` subclass.
- `__init__(self, history_size=100)`:
  - `collections.deque(maxlen=history_size)` for amplitude history.
  - `self.set_draw_func(self._draw)` — GTK4 DrawingArea pattern.
  - `self._timer_id = GLib.timeout_add(33, self._tick)` — ~30fps refresh.
  - `self.set_content_width(200)` and `self.set_content_height(60)`.
- `push_amplitude(self, rms: float)` — appends to deque. Returns `False` (for GLib.idle_add to not repeat).
- `_tick(self) -> bool` — calls `self.queue_draw()`, returns `True` (keep timer running). CRITICAL: must return True explicitly.
- `_draw(self, area, ctx, width, height)`:
  - Fill background with blue (#2164AD): `ctx.set_source_rgb(0.13, 0.39, 0.68)`, rectangle, fill.
  - If no amplitude data, draw a flat center line (white, thin) as idle indicator and return.
  - White waveform fill: `ctx.set_source_rgba(1.0, 1.0, 1.0, 0.9)`.
  - Draw mirrored waveform as a filled shape (not stroke-only):
    - Forward pass: top edge from left to right (`mid_y - bar_h` for each amplitude)
    - Reverse pass: bottom edge from right to left (`mid_y + bar_h`)
    - `ctx.close_path()` then `ctx.fill()`.
  - Scale factor: `bar_h = min(amp * mid_y * 5.0, mid_y - 2)` — clamp to avoid overflow.
  - Use `cairo.LINE_JOIN_ROUND` on context before starting path for smooth joins if using stroke. Since we fill, line_join is not needed — but set_line_width(0) and fill is cleaner.
- `stop(self)` — removes timer via `GLib.source_remove(self._timer_id)`.

Important: The `push_amplitude` method MUST return `False` when called via `GLib.idle_add` — returning True would cause GLib to call it again repeatedly.
  </action>
