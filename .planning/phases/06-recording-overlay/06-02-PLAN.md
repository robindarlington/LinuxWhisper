<objective>
Wire the overlay module into the dictation pipeline so it appears during recording and shows live audio waveform data.

Purpose: The overlay module from Plan 06-01 is self-contained but disconnected. This plan connects it to the pipeline state machine (show on RECORDING, hide on anything else), hooks the audio recorder's callback to compute and send RMS amplitude, adds overlay configuration to defaults, and ensures clean lifecycle management in the daemon.

Output: A fully integrated recording overlay — press the hotkey to start recording and the waveform overlay appears; release (or toggle-stop) and it disappears. The waveform moves with the user's voice in real-time.
</objective>

- Add an `_on_amplitude_callback` attribute initialized to `None` in `__init__`.
- Add a `set_amplitude_callback(self, callback)` method that stores the callback. The callback signature is `callback(rms: float)`.
- In the existing `_callback` method, AFTER `self._queue.put(indata.copy())`, compute RMS and invoke the callback:
```python
if self._on_amplitude_callback is not None:
    # Compute RMS amplitude — trivial cost on ~1024 samples
    chunk = indata if indata.ndim == 1 else indata.mean(axis=1)
    rms = float(np.sqrt(np.mean(chunk ** 2)))
    self._on_amplitude_callback(rms)
```
- numpy is already imported in this file (it's used in stop() and save_wav()).
- CRITICAL: The callback MUST be non-blocking. The OverlayManager.send_amplitude writes to a pipe which is essentially non-blocking for small data (a few bytes). This is safe inside the audio callback.
- In `start()`, no changes needed — the callback is optional and None-checked.

```python

overlay_config = config.get("overlay", {})

    self._overlay = OverlayManager(config=overlay_config)

```
- Wire the amplitude callback on the recorder:
```python
if self._overlay is not None:
    self._recorder.set_amplitude_callback(self._on_audio_amplitude)
```

Add `_on_audio_amplitude` method:
```python
def _on_audio_amplitude(self, rms: float) -> None:
    """Forward amplitude from audio callback to overlay subprocess."""
    if self._overlay is not None and self._overlay.is_running():
        self._overlay.send_amplitude(rms)
```

Modify `_on_hotkey_press` — show overlay when recording starts:
- In the HOLD mode `IDLE` branch, AFTER `self._recorder.start()`, add:
