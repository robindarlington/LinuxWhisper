# Plan 08-01: Package Prerequisites and AUR Files

**Phase:** 8 — Distribution
**Goal:** Create all files needed for the AUR package: LICENSE, pyproject.toml license field, PKGBUILD, .install file, system config files, service module update, and README update
**Depends on:** All previous phases (1-7 complete)
**Requirements:** PKG-01, PKG-02

## Overview

This plan creates everything needed for the `linuxwhisper-git` AUR package. It addresses four gaps in the current codebase (missing LICENSE file, missing pyproject.toml license field, no AUR packaging files, service module unaware of system-wide installs) and creates the complete `aur/` directory with PKGBUILD, .install file, and system configuration files (udev rule, modules-load.d, systemd service). It also updates the README to reflect the current project status and AUR installation option.

Plan 08-02 will validate the package by building it, running namcap, and generating .SRCINFO.

### Task 2: Create AUR package files and update service module

**Files:**
- `aur/PKGBUILD`
- `aur/linuxwhisper.install`
- `src/linuxwhisper/service/__init__.py`
- `README.md`

**Action:** Create and Modify

**2a. Create `aur/PKGBUILD`**

Create the `aur/` directory and write `PKGBUILD` for a `-git` VCS package. Use the template from 08-RESEARCH.md with these specifics:

- `pkgname=linuxwhisper-git`
- `pkgver=0.1.0` (pkgver() function will override at build time)
- `pkgrel=1`
- `pkgdesc="Linux desktop voice dictation tool using local Whisper"`
- `arch=('x86_64')`
- `url="https://github.com/robindarlington/linuxwhisper"`
- `license=('MIT')`
- `depends`: All runtime deps from research (python>=3.11, python-click, python-tomli-w, python-xdg-base-dirs, python-evdev, python-sounddevice, python-faster-whisper, python-scipy, python-gobject, gtk4, gtk4-layer-shell, portaudio)
- `makedepends`: git, python-build, python-installer, python-wheel, python-setuptools, python-setuptools-scm
- `optdepends`: ydotool (recommended), wtype, xdotool, wl-clipboard, xclip — each with a description string
- `provides=('linuxwhisper')`, `conflicts=('linuxwhisper')`
- `install=linuxwhisper.install`
- `source=("${pkgname}::git+https://github.com/robindarlington/linuxwhisper.git")`
- `sha256sums=('SKIP')`

**pkgver() function:** Try `git describe --long --abbrev=7` first, fall back to `printf "0.1.0.r%s.%s"` with rev-list count and short hash. Exactly as in the research template.

**build() function:** `cd "$pkgname"` then `python -m build --wheel --no-isolation`.

**package() function:** `cd "$pkgname"` then:
1. `python -m installer --destdir="$pkgdir" dist/*.whl` — install the wheel
2. `install -Dm644 LICENSE "$pkgdir/usr/share/licenses/$pkgname/LICENSE"` — install license
3. Install systemd user service to `$pkgdir/usr/lib/systemd/user/linuxwhisper.service` using heredoc. ExecStart must be `/usr/bin/python -m linuxwhisper` (NOT venv path). Include all fields from the research template (After, PartOf, Wants, StartLimitIntervalSec, StartLimitBurst, Restart, RestartSec, Environment, TimeoutStopSec, ExecReload).
4. Install udev rule to `$pkgdir/usr/lib/udev/rules.d/80-linuxwhisper-uinput.rules` with content: `KERNEL=="uinput", GROUP="input", MODE="0660"`
5. Install modules-load.d config to `$pkgdir/usr/lib/modules-load.d/linuxwhisper-uinput.conf` with content: `uinput`

**2b. Create `aur/linuxwhisper.install`**

Create the `.install` file with `post_install()` and `post_upgrade()` functions. The `post_upgrade` function should call `post_install`.

The `post_install` message must cover ALL setup steps from MEMORY.md and research:

1. Add user to input group: `sudo usermod -aG input $USER`
2. Load uinput kernel module: `sudo modprobe uinput` (explain it persists via modules-load.d on next boot)
3. Enable ydotool: `systemctl --user enable --now ydotool` (note: service name is `ydotool`, NOT `ydotoold`)
4. Log out and back in for group changes
5. Start LinuxWhisper: show both one-time start (`linuxwhisper start`) and systemd service (`systemctl --user enable --now linuxwhisper`)
6. Troubleshooting: `journalctl --user -u linuxwhisper -f`

Use a clear box format with `=====` separators. Use `$USER` (escaped as `\$USER` in the heredoc) so it prints literally for the user to copy-paste.

**2c. Update `src/linuxwhisper/service/__init__.py`**

Add a function to detect system-installed service files and update the install flow:

1. Add constant: `SYSTEM_SERVICE_PATH = Path("/usr/lib/systemd/user") / SERVICE_NAME`

2. Add function `is_system_service_installed() -> bool` — returns `SYSTEM_SERVICE_PATH.is_file()`.

3. Modify `install_service()`:
   - At the top, before any file writing, check `is_system_service_installed()`.
   - If True, raise `RuntimeError("A system-wide service file exists at /usr/lib/systemd/user/linuxwhisper.service (installed by the AUR package). Remove the package or use 'systemctl --user enable --now linuxwhisper' directly.")`.
   - Leave the rest of the function unchanged.

4. Update `is_service_installed()` to also return True if the system service file exists. Change to: `return get_service_path().is_file() or SYSTEM_SERVICE_PATH.is_file()`.

5. Add `is_system_service_installed` and `SYSTEM_SERVICE_PATH` to `__all__`.
