# Plan 08-02: Build Validation and Testing

**Phase:** 8 — Distribution
**Goal:** Validate the AUR package builds correctly, passes namcap, generates .SRCINFO, and the installed package works
**Depends on:** Plan 08-01 (package files must exist)
**Requirements:** PKG-01, PKG-02

## Overview

This plan validates everything created in 08-01 by actually building the package, running namcap on both the PKGBUILD and the built package, generating .SRCINFO, and verifying the wheel contents. This is the final quality gate before the package can be submitted to the AUR.

Note: Building with `makepkg` requires the git source URL to be accessible. Since the GitHub repo may not exist yet, this plan includes a workaround: temporarily modify the PKGBUILD source to use the local git repo (`file://` URL) for build testing, then revert to the GitHub URL for the final version. If the GitHub repo IS accessible, skip the local source workaround.

## Tasks

### Task 1: Build package, run namcap, and generate .SRCINFO

**Files:**
- `aur/PKGBUILD` (temporary modification then revert)
- `aur/.SRCINFO` (generated)

**Action:**

**1a. Test PKGBUILD syntax**

Run `bash -n aur/PKGBUILD` to verify valid bash syntax. Run `bash -n aur/linuxwhisper.install` to verify the install script syntax. Fix any syntax errors before proceeding.

**1b. Build the package locally**

First, check if the GitHub source URL is accessible:
```bash
git ls-remote https://github.com/robindarlington/linuxwhisper.git HEAD 2>/dev/null
```

If NOT accessible (expected — no remote configured yet), temporarily modify the PKGBUILD source line for local testing:
1. Save a backup: `cp aur/PKGBUILD aur/PKGBUILD.bak`
2. Replace the `source=` line with: `source=("${pkgname}::git+file:///home/rob/Documents/Projects/LinuxWhisper")`
3. Build with `cd /home/rob/Documents/Projects/LinuxWhisper/aur && makepkg -sf` (the `-f` forces rebuild, `-s` installs missing makedepends)
4. After successful build, restore the original: `cp aur/PKGBUILD.bak aur/PKGBUILD && rm aur/PKGBUILD.bak`

If the GitHub URL IS accessible, build directly: `cd /home/rob/Documents/Projects/LinuxWhisper/aur && makepkg -sf`

Note: `makepkg` must be run from the directory containing the PKGBUILD. The build will take a few minutes as it clones the repo, builds the wheel, and packages everything.

**1c. Validate with namcap**

Run both validations:
```bash
namcap aur/PKGBUILD
namcap aur/linuxwhisper-git-*.pkg.tar.zst
```

**Expected namcap output:** Some warnings are acceptable and expected:
- `W: Dependency X detected and not included` for optional deps — these are optdepends, not errors
- Warnings about AUR-only dependencies (python-sounddevice, python-faster-whisper) — namcap can't resolve AUR packages

**NOT acceptable (fix if seen):**
- `E: missing-license` — means LICENSE wasn't installed correctly in package()
- `E: missing-dependency` for official repo packages — means depends array is incomplete
- Errors about file permissions or ownership

If there are real errors, fix the PKGBUILD and rebuild. Common fixes:
- Missing dependency: add to `depends` array
- License issue: verify `install -Dm644 LICENSE` line in package()
- Permission issue: verify `install -Dm644` mode flags

**1d. Verify wheel contents**

After successful build, check that the wheel inside `aur/src/linuxwhisper-git/dist/` contains the expected files:
```bash
python -m zipfile -l aur/src/linuxwhisper-git/dist/*.whl
```

Must contain:
- `linuxwhisper/__init__.py`
- `linuxwhisper/__main__.py`
- `linuxwhisper/cli/commands.py`
- `linuxwhisper/service/__init__.py`
- Entry point metadata (in `*.dist-info/entry_points.txt`)

If the wheel is empty or missing files, the `pyproject.toml` `[tool.setuptools.packages.find]` configuration has a problem.

**1e. Verify installed package contents**

Check that the built package contains all expected files:
```bash
tar -tf aur/linuxwhisper-git-*.pkg.tar.zst | grep -E "(linuxwhisper|udev|modules-load|systemd|LICENSE)"
```

Must contain paths for:
- `/usr/lib/python3.*/site-packages/linuxwhisper/` — Python package
- `/usr/bin/linuxwhisper` — CLI entry point
- `/usr/lib/systemd/user/linuxwhisper.service` — systemd service
- `/usr/lib/udev/rules.d/80-linuxwhisper-uinput.rules` — udev rule
- `/usr/lib/modules-load.d/linuxwhisper-uinput.conf` — module loading
- `/usr/share/licenses/linuxwhisper-git/LICENSE` — license file

**1f. Generate .SRCINFO**

Generate the AUR metadata file (must use the GitHub source URL, not the local one):
```bash
cd /home/rob/Documents/Projects/LinuxWhisper/aur && makepkg --printsrcinfo > .SRCINFO
```

Note: If the PKGBUILD was temporarily modified for local testing and has been restored to the GitHub URL, `--printsrcinfo` will use the correct URL. If `makepkg --printsrcinfo` fails because the source URL is unreachable, that's OK — the .SRCINFO can still be generated (it doesn't actually fetch sources). If it does fail, extract the SRCINFO manually by running `makepkg --printsrcinfo` with the local source variant and then editing the source line in the output.

**1g. Clean up build artifacts**

Remove the build artifacts (large files, not needed in git):
```bash
rm -rf aur/src/ aur/pkg/ aur/linuxwhisper-git-*.pkg.tar.zst aur/linuxwhisper-git/
```

The `aur/` directory should contain only: `PKGBUILD`, `linuxwhisper.install`, `.SRCINFO`.

**Verify:**
- `bash -n aur/PKGBUILD` exits 0
- `bash -n aur/linuxwhisper.install` exits 0
- `ls aur/.SRCINFO` — file exists
- `grep "pkgname = linuxwhisper-git" aur/.SRCINFO` — correct package name in SRCINFO
- `ls aur/` shows only PKGBUILD, linuxwhisper.install, .SRCINFO (no build artifacts)
- namcap reported no errors (warnings about AUR deps are acceptable)

**Done:**
- Package builds successfully with `makepkg`
- namcap validation passes with no errors on both PKGBUILD and built package
- Wheel contains all linuxwhisper modules and entry point
- Built package contains CLI binary, systemd service, udev rule, modules-load config, and license
- `.SRCINFO` generated and committed
- No build artifacts left in `aur/` directory

### Task 2: Verify post-install message and end-to-end flow

**Files:** (no file changes — verification only)

**Action:**

This is a verification-only task to confirm the post-install message displays correctly and the overall package is ready.

**2a. Verify .install file output**

Source the install file and call post_install to see the actual output:
```bash
bash -c 'source aur/linuxwhisper.install && post_install'
```

Verify the output:
- Contains `sudo usermod -aG input $USER` (with literal $USER, not expanded)
- Contains `sudo modprobe uinput`
- Contains `systemctl --user enable --now ydotool` (NOT ydotoold)
- Contains logout/login instruction
- Contains both `linuxwhisper start` and `systemctl --user enable --now linuxwhisper` options
- Contains `journalctl --user -u linuxwhisper -f` for troubleshooting

**2b. Verify service module system detection**

Run in the project venv:
```bash
.venv/bin/python -c "
from linuxwhisper.service import is_system_service_installed, SYSTEM_SERVICE_PATH
print(f'System service path: {SYSTEM_SERVICE_PATH}')
print(f'System service installed: {is_system_service_installed()}')
"
```

Expected: `is_system_service_installed()` returns False on the development machine (no AUR package installed). The path should be `/usr/lib/systemd/user/linuxwhisper.service`.

**2c. Verify README updates**

Check the README:
- `grep "yay -S linuxwhisper-git" README.md` — AUR instructions present
- `grep "HOME" README.md` — hotkey reference corrected from F13 to HOME
- Confirm project status checklist has toggle mode, systemd service, and AUR package checked

**Verify:**
- Post-install message displays all 5 setup steps with correct commands
- Service module correctly reports system service status
- README has AUR installation instructions and updated status

**Done:**
- Post-install message verified to show correct, copy-pasteable commands
- Service module system-wide detection works correctly
- README reflects current project state with AUR installation option
- Phase 8 deliverables are complete and ready for AUR submission (once GitHub repo is public)
